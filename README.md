# Investigación de Mercado

Este repositorio documentará una investigación de mercado orientada a identificar oportunidades para actuar como **proveedor o intermediario de algún producto**.

## Objetivo

Investigar y analizar productos, mercados, proveedores, demanda, competencia, precios, márgenes y posibles canales de comercialización, con el fin de identificar una oportunidad de negocio viable.

## Alcance inicial

- Identificación de productos y categorías con potencial.
- Análisis de demanda y tendencias del mercado.
- Investigación de proveedores y fabricantes.
- Evaluación de modelos de intermediación y distribución.
- Análisis de competencia y precios.
- Estimación de costos, márgenes y rentabilidad.
- Identificación de riesgos y barreras de entrada.

Los resultados de la investigación se irán documentando en este repositorio para mantener un historial trazable de las fuentes, análisis y decisiones tomadas.
